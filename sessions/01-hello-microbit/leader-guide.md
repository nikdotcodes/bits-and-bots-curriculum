# Session 01: Hello, micro:bit!

**Age:** 7–11 · **Duration:** 70 minutes · **Project:** Scrolling name badge

## Learning outcomes

- Identify the micro:bit LED display and A/B buttons.
- Build a sequence of blocks in MakeCode.
- Download and test a program on a physical micro:bit.

## Equipment

One micro:bit per child or pair, laptop with MakeCode, USB data cable, power supply/batteries, projector and a prepared working demo.

## Before children arrive

- [ ] Open https://makecode.microbit.org/ on each laptop.
- [ ] Test USB transfer on the exact Linux/browser combination being used; prepare drag-and-drop `.hex` transfer as fallback.
- [ ] Confirm attendance, supervision, collection and accessibility arrangements.
- [ ] Prepare a micro:bit showing a scrolling message.

## 70-minute plan

| Time | Activity | Leader notes |
|---|---|---|
| 0–10 | Welcome and demo | Show the micro:bit; ask what it might do. |
| 10–20 | Explore MakeCode | Introduce simulator and `on start` block. |
| 20–45 | Build a name badge | Add `show string`, change text, test simulator and hardware. |
| 45–60 | Make it yours | Add an icon, repeat or change the message. |
| 60–70 | Share and tidy | Demonstrate, save, disconnect and count devices. |

## Teaching notes

Model one action at a time. Avoid putting full names or personal information into public shared projects. For younger children, allow a nickname or short invented message.

## Troubleshooting

- No display: check power and whether the `.hex` was copied to the MICROBIT drive.
- No device detected: use download and copy rather than WebUSB.
- Code not behaving: check the blocks are inside `on start` and re-download.

## Differentiation

**Get started:** Show a word or initials. **Make it yours:** Add an LED icon. **Level up:** Use button A to show one message and button B for another.
